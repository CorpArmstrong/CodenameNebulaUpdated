# План: какие скрипты CNN реально используются (28.10.2026)

Цель — каталог всех классов UnrealScript мода (276 файлов в `CNN/Classes`, 1 в `ApocalypseInside/Classes`) с
ответом для каждого: **работает ли он в игре, где и почему**, и что из неработающего можно убрать. Сейчас это
план; ничего не удаляется, пока каталог не просмотрен.

## Почему не хватает CLASSES_MAP.md

`CLASSES_MAP.md` (25.04.2026) считает класс достижимым, если его имя встречается **где угодно**: в коде любого
класса, в таблице имён карты (`grep -a`), в `.con`. Отсюда «0 недостижимых». Но:

- упоминание в коде мёртвого класса делает «живым» и того, на кого он ссылается;
- имя в таблице имён карты — не актёр на карте (это может быть свойство, тег, событие);
- не отделены отладочные классы (мост, тестовые карты `Entryv2`, `DX.dx`) и шаблоны импорта `Deco*`
  (`extends Object abstract`, нужны только компилятору ради `#exec`);
- нет проверки во время игры.

## Категории каталога

| Категория | Значит |
|---|---|
| `MAP` | Актёр этого класса стоит на поставляемой карте (число и карты) |
| `ROOT` | Задан в ini / движке: `CNNGameInfo`, `TantalusDenton`, `CNNHUD`, `CNNRootWindow`, меню |
| `SPAWN` | Создаётся кодом живого класса (`Spawn`, `class'X'`, `DynamicLoadObject`, defaultproperties, `.con`) |
| `BASE` | Только как родитель живых классов |
| `RUNTIME` | Подтверждён в игре: загружен на какой-то карте/в каком-то состоянии (`obj list class=Class`) |
| `IMPORT` | Шаблон `#exec` (меши, текстуры, звуки, разговоры, текст) — нужен при компиляции |
| `DEV` | Только для разработки: мост, тесты, отладочные карты |
| `DEAD` | Ни одного пути от живого корня |
| `DEAD-CHAIN` | Используется только мёртвыми классами |

## Шаги

### 0. База (ветка `chore/script-catalog`)
Компиляция 0/0, `tools/cnn_regression.ps1` 30/30, `cnn_assetcheck.ps1` по 9 картам — исходная точка, с которой
сравнивается всё дальнейшее.

### 1. Статический граф классов — `tools/uc_classgraph.js` (новый)
Разбор каждого `.uc`: имя, родитель, файл, строки, комментарий-шапка, подсистема (по префиксу и папке
`CLASSES_MAP.md`). Рёбра «A ссылается на B»:
- `extends`, `class'X'`, `class<X>`, `Spawn(class'X')`, `X(...)`-приведения, `foreach AllActors(class'X')`;
- **по имени**: `IsA('X')`, `ClassIsChildOf`, `DynamicLoadObject("CNN.X")`, `GetPropertyText`/строки с `CNN.` —
  их regex не поймает как класс, поэтому отдельный проход по строковым литералам;
- defaultproperties (`MenuClass=`, `buttonDefaults(...)=(Invoke=Class'CNN.X')`, `InitialInventory`, `CarcassType`…);
- `#exec`: какой ресурс класс производит (для связи с аудитом ресурсов `tools/asset_usage.js`).

### 2. Актёры на картах — `pkg_probe.js`
По экспортам, а не по таблице имён: каждый актёр класса CNN на 9 поставляемых картах + `Entryv2`/`DX.dx`
(отдельно, как `DEV`). Плюс свойства-классы у актёров карт: `ClassProximityType`, `SpawnClass`,
`InventoryType`, `ConPlay`-классы, `MissionScript` из `DeusExLevelInfo`.

### 3. Прочие источники
- `.con` — `tools/con_dump.js`: классы в `TransferObject`/`CheckObject`, спавн актёров разговором;
- `System/CNN.ini`, `CNNUser.ini`, `ModSetup.cs` (`InjectIniProperties`) — корни движка;
- `CNNText` / тексты — классы, на которые ссылается текст (`<DC=...>`), если есть.

### 4. Достижимость от корней
Корни: ini + актёры карт + разговоры. Замыкание **только из живых** классов. На выходе — категории
`MAP/ROOT/SPAWN/BASE/IMPORT/DEAD/DEAD-CHAIN`; `DEV` — по списку (мост `CNNAgentBridge`, `MissionIntroTest`,
`*Test*`, классы только с отладочных карт).

### 5. Проверка в игре
Мост: на каждой карте и в ключевых состояниях (меню, новая игра, вступление на Луне, прибытие в доки,
4 концовки, титры, загрузка сохранения) — `RAW obj list class=Class` (как `tools/cnn_objdump.ps1`). Пакеты
грузятся лениво, поэтому загруженный класс — реально нужный (с поправкой: ссылка в defaultproperties тоже
грузит). Сравнить со статикой: `RUNTIME`, но статически `DEAD` → дыра в разборе; статически живой, но ни разу не
загружен → кандидат на ручную проверку (ветка сюжета, которую прогон не прошёл).

### 6. Каталог — `CNNDocs/Script_Catalog.md` + `Script_Catalog.csv`
Строка на класс: категория, где используется (карта × число / кем создаётся / из какого разговора), подсистема,
строк кода, автор/источник по истории git (AI, CNN 2016-2017, добавлено 2026), заметки. Сводка по категориям и
подсистемам. `CLASSES_MAP.md` получает ссылку на каталог как на актуальный.

### 7. Решения (после просмотра)
Кандидаты `DEAD`/`DEAD-CHAIN` — вам на решение: удалить, оставить для будущих карт, перенести в `_Backups`.
Удаление — отдельной веткой, пачками, каждая: компиляция 0/0, регрессия 30/30, assetcheck 0 новых.

## Подводные камни

- **Сохранения**: удалённый класс, который был в старом сохранении, ломает его загрузку. До релиза v1.5.0
  сохранений у игроков нет, но у вас и тестов — есть.
- **По имени**: `IsA('Name')`, `Tag`/`Event` совпадают с именами классов — нельзя считать ссылкой без проверки.
- **Ресурсы**: удаление класса-шаблона `Deco*` уберёт меши/текстуры из `CNN.u` — сверка с `asset_usage.js`.
- **Наследование ресурсов**: класс может быть мёртв, а его меш используется картой напрямую (`Mesh=`).
- **Вне CNN.u**: `ApocalypseInside/Classes` (1 класс-заглушка) и стороннее (`GaussGun.u`, `PFAD.u`,
  `DXRVNewVehicles.u`) — в каталог отдельным разделом, без разбора их внутренностей.

## Оценка

Шаги 1–4 и черновик каталога — одна сессия; шаг 5 (прогон по картам и состояниям) — ещё одна, частично
автоматически через мост; шаг 7 — по вашему решению.
