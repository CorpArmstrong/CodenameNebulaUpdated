# Ревью однородности кода (05.10.2026)

Цель: код, добавленный с 2026-04 (сессии Claude Code), должен читаться как часть того же проекта,
что и исходный код CNN (до коммита `1faa297`, 2024-09-26), а не как вставки
автосгенерированного кода. При этом всё должно работать, и рефакторинг ничего не должен
сломать.

## Каким был исходный код

- Шапки как в ванильном Deus Ex: `//====` / `//----` с именем класса; у функций короткий блок
  `// FuncName()` и одна-две строки о назначении.
- Комментариев мало: 3–10 % строк, короткие, по делу, без дат и истории.
- В классах игры только игровая логика: ни отладочных команд, ни логирования.
- Один класс — одна задача (`QuestSystem`, `ChineseSkillController`, отдельные триггеры).
  Скрипт миссии L2 занимал 46 строк.

## План рефакторинга (поэтапно, каждый этап — с регрессией)

**Этап 0. Регрессионный набор — готов (05.10.2026), эталон 30/30 PASS.** (`tools/cnn_regression.ps1`): один запуск мостом проверяет
4 концовки, ветки Social Boss (ATTACK, сдаться, китайский), передачу оружия, сейвы S2/S5/S7.
Его прогоняем до и после каждого этапа; результат должен совпасть.

**Этап A. Комментарии, без изменения логики — готов (05.10.2026), регрессия 30/30.** Правились только комментарии, добавленные Claude; исходные комментарии авторов сохранены (проверка `tools/uc_codecmp.js --keep 1faa297`), а три авторских, убранных в прошлых сессиях при живом коде, возвращены. Код побайтно тот же. Комментарии команд моста перепишутся на этапе B при переносе. Шапки в ванильном стиле; у функции 1–3 строки
о том, *зачем* она нужна. Даты, имена, история попыток — убрать: история есть в git и в
`CNNDocs/`. Цель — 5–10 % комментариев. Риск минимальный: сборка и одна концовка.

**Этап B. Инструменты разработчика — вон из `TantalusDenton`.** Консольная команда должна
висеть на игроке, поэтому в `TantalusDenton` остаётся одна тонкая точка входа (`CNNAgentRun`), а
реализация команд уходит в `CNNAgentBridge` (он уже есть и отвечает за мост). Отладочные
`CNNGoto`/`CNNFire`/… — туда же. `TantalusDenton` возвращается примерно к исходному объёму.

**Этап C. Разделить `Chapter06L2`.**

- Social Boss — в отдельный класс-актёр (`CNNSocialBoss`), который создаёт скрипт миссии.
  Актёры уровня, в отличие от скрипта миссии, сохраняются в сейв, так что флаги-«зеркала»
  состояния сцены станут не нужны.

**Этап D. Мелочи стиля** (п. 6) — заодно с A–C.
