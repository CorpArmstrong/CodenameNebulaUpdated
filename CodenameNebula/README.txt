------------------------------------------------------------------------------
  1. ABOUT
------------------------------------------------------------------------------

  Codename Nebula is a story campaign for Deus Ex. You play Tantalus, an agent
  sent from a lunar base to the space station Ophelia. The campaign continues
  the Apocalypse Inside mod and has several endings.


------------------------------------------------------------------------------
  2. REQUIREMENTS
------------------------------------------------------------------------------

  - A full, legal copy of Deus Ex: Game of the Year Edition, patch 1112fm:
    Steam, GOG, or a CD copy patched to 1112fm.
  - Windows 10 or 11 (.NET Framework 4.7.2, part of Windows 10 1803 and later).

  The mod runs on the game's own Direct3D 9 renderer. Kentie's Direct3D 10
  and the OpenGL renderer are used if they are installed in the game.


------------------------------------------------------------------------------
  3. INSTALLATION
------------------------------------------------------------------------------

  Run the installer. It finds the game itself (Steam, GOG or CD) and installs
  into the folder "CodenameNebula" inside the game folder. The mod keeps its
  files and saves there and does not change the game's own files or settings.

  If the game was never patched to 1112fm, or another mod replaced DeusEx.u,
  the installer warns you before going on.


------------------------------------------------------------------------------
  4. PLAYING
------------------------------------------------------------------------------

  Start "Codename Nebula" from the desktop or the Start menu. The launcher
  starts the game the right way for your copy (through Steam for the Steam
  version).

  Settings  - renderer, resolution, fullscreen or window.
  Repair    - restores the mod's settings when the game will not start.

  Saves are kept in CodenameNebula\Save and do not mix with Deus Ex saves.
  You cannot save during a conversation.


------------------------------------------------------------------------------
  5. TROUBLESHOOTING
------------------------------------------------------------------------------

  Black screen, or "Failed resetting mode" on start
    The game was set to a renderer that does not work on current Windows
    (the in-game "Rendering Device..." list still offers the 1999 Direct3D
    device). Open the launcher's Settings, choose Direct3D 9, and start again.

  The game renders (it shows in a screen capture) but the monitor stays black
    Fullscreen does not reach the monitor (HDR, a second monitor, refresh
    rate). Turn Fullscreen off in the launcher's Settings.

  Anything else
    Press Repair in the launcher. If that does not help, send the game log
    to the e-mail above: the newest .log file in the game's System folder,
    or in Documents\Deus Ex\System with Kentie's launcher, together with
    CodenameNebula\System\CNNSetup.log.


------------------------------------------------------------------------------
  6. UNINSTALLING
------------------------------------------------------------------------------

  Use "Uninstall Codename Nebula" in the Start menu, or Windows Settings >
  Apps. Only the files the mod added are removed; the game and other mods are
  left as they were.
