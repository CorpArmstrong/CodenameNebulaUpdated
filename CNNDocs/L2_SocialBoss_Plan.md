# План: Social Boss у штурвала (вариант А)

Ветка: `feature/l2-social-boss` (от `master` @ `f57c88d`).
Решение (02.10.2026): оживить **уже написанную и озвученную** сцену `SocialBoss` из
`OpheliaL2.con` кодом, без ConEdit. Сцена **заменяет охрану из 4 аватаров** на мостике.
Полноценный HR-стиль (шкала убеждения, «чтение» собеседника, новая озвучка) — не делаем.

Исследование и факты: память `project_social_boss_research`, схема авторов
`CNNDocs/Story/CNNL2StoryFlowchart.pdf`.

## Что уже есть

Разговор `SocialBoss` (владелец Мефистофель, условие `ReadyForSocialBoss`, запуск по
радиусу 500): ~80 событий, 66 озвученных реплик.

```
Вступление ── улики в доках уничтожены? (AllObjectsDestroyed)
   ├─ нет → Вонг расстреливает солдата MJ12 (триггер MikeExecutesMJ12Troop)

         [Угрожать Мефистофелю] → MephistophelesAngry → расстрел Армстронга

Выбор 2: [Посеять сомнения] → SeedsOfDoubtPlanted → Выбор 3
         [Игнорировать угрозу] → расстрел Джонсона → Выбор 3
Выбор 3 (узел, возвращается):
         [Компромисс с Мефистофелем] → назад к Выбору 3
         [Обвинить Вонга в лицемерии] → WongParanoid → расстрел Саманты → назад

         [УСТРОИТЬ АПОКАЛИПСИС]      → «сдаться», конец
```

Все действия (расстрелы, выстрелы, атака) сейчас — **комментарии-заглушки** в `.con`.

## Почему сейчас не работает

1. Заложники в разговоре — `CorpArmstrongHostage`, `DrJohnsonHostage`,
   `SamanthaReedHostage`; на карте эти персонажи стоят у штурвала, но под именами
   `CorpArmstrong`, `DrJohnson`, `SamanthaReed`. Движок не находит участников.
2. Действия — комментарии, движок их пропускает.
3. Исходы не связаны с концовками; на мостике вместо сцены — охрана из 4 аватаров.

## Исходы → концовки (решено)

| Исход сцены | Что происходит | Концовка |
|---|---|---|
| **Сдался** («УСТРОИТЬ АПОКАЛИПСИС») | флаг `PlayerGaveUp` | **Mutiny** |
| **Вонг убил Мефистофеля** (китайские подходы, успех) | Мефистофель погибает → штурвал открыт | **Hijacking** (штурвал) |
| **Атака** / «Вонг атакует игрока» | Вонг и Мефистофель враждебны; когда оба мертвы → штурвал открыт | **Hijacking** (штурвал) — *предложение, подтвердить* |
| Игрок погиб | как сейчас | Mutiny |
| Таймер MJ12 истёк | как сейчас | Conspiracy |
| Капсула | как сейчас (сцену можно не проходить) | Transcend |

## Решения по умолчанию (подтвердить или поправить)

- **D1. Атака** ведёт к бою с Вонгом и Мефистофелем; штурвал открывается, когда оба мертвы.
- **D2. Таймер MJ12 на паузе**, пока идёт разговор (иначе 4 минуты съедает диалог).
- **D3. Вонг после выстрела в Мефистофеля** — по схеме «убивает Мефистофеля и себя».
  Если реплики после выстрела (шаг 0) этому противоречат — делаем как в `.con`.
- **D4. Цель Дедала «Meet Daedalus in the command center»** возвращаем: она ведёт к сцене.

## Итоги шага 0 (02.10.2026)

Граф снят из движка командой моста `CONEVENTS DrMephistopheles SocialBoss` (точно, не
эвристика). Отличия от предположений:

- **Китайская проверка была сломана.** В `.con` у «Извиниться» и «Манипулировать» записан
  навык `Chinese` уровня 3, но движок не находит класс с таким именем и оставлял
  `skillNeeded` пустым — «Извиниться» был доступен всем. Исправлено в `CNNConPlay`
  (подставляется `AiSkillChinese`, уровень 3) — так же, как раньше классы оружия.
- **Китайские ветки линейны:** Вонг стреляет в Мефистофеля → «Your Chinese sucks heck» /
  «You still Dontgivafucker!» → **атакует игрока** → конец. Самоубийства в репликах нет,
  поэтому по D3 делаем как в разговоре: Вонг убивает Мефистофеля, затем бой с Вонгом.
  Штурвал открывается, когда **Мефистофель и Вонг мертвы** — одно правило для всех путей.
- «Манипулировать» дополнительно требует `WongParanoid` (ставится в «Обвинить Вонга»,
  которое требует `SeedsOfDoubtPlanted`). Видеозапись упоминается прямо в этой реплике.
- Тексты комментариев при загрузке приходят мусором, поэтому точки действий берутся по
  позиции: комментарий [5] + триггер [6] (солдат MJ12), [25] `ExecuteArmstrong`,
  [37] `ExecuteJohnson`, [53] (Саманта), [65]/[76] (выстрел в Мефистофеля),
  [68]/[79] (Вонг атакует).

Мост теперь проходит разговоры от третьего лица: `TALK`, `CONSTATE`, `CHOOSE`, `CONRUN`
(автопроход с заданными номерами выборов). Проверено: `MagdaleneHijackTheStation` прошёл
целиком и выставил `CanArmMagdalene`. Значит, ветки Social Boss можно гонять мостом,
ручная проверка нужна только для «как это выглядит».

## Шаги

**0. Разбор (без изменений кода).** — сделано, см. выше.

  флаги), есть ли Random/CheckFlag внутри китайских веток, что идёт после «MW shoots Meph».

- Найти «солдата MJ12-заложника» для `MikeExecutesMJ12Troop` (или выбрать, кого).

**1. Участники и запуск.** (`Chapter06L2`)
- При загрузке L2 переименовать заложников у штурвала (`BindName` → `*Hostage`), только
  экземпляры у мостика (у Саманты есть закадровый двойник).
- Убедиться, что сцена стартует по радиусу у Мефистофеля только после открытия двери на
  мостик (`MJ12TimerStarted`), и не стартует второй раз.
- Вернуть цель Дедала (D4): убрать её из `DropDeadGoals`.

**2. Убрать охрану.** `SpawnBridgeGuards`, `AggroBridgeGuards`, `IsBridgeClear` и их
вызовы; новое условие штурвала — флаг «мостик свободен» (`WheelUnlocked`), который ставит
сцена (шаги 3–4). Мефистофель по-прежнему переносится за штурвал.

**3. Действия по комментариям.** (`CNNConPlay`)
Перехват событий-комментариев при проигрывании (в `.con` они пропускаются):

| Комментарий | Действие |
|---|---|
| Wong kills MJ12 trooper / триггер `MikeExecutesMJ12Troop` | убить солдата-заложника |
| Wong kills Armstrong. | убить Армстронга |
| MW kills Johnson | убить Джонсона |
| MW Kills Samantha | убить Саманту |
| MW shoots Meph | убить Мефистофеля (D3: и Вонга) → `WongBetrayedMeph`, `WheelUnlocked` |
| MW attacks player | Вонг (и Мефистофель) враждебны → бой |

Вонгу выдаётся пистолет, расстрел — выстрел/урон от Вонга, чтобы выглядело как выстрел.

**4. Исходы.**

- Оба мертвы (любым путём) → `WheelUnlocked`.
- Штурвал (`CheckShipsWheel`): вместо «охрана перебита» — `WheelUnlocked`; Магдалена
  жива — как сейчас.

**5. Таймер MJ12 на паузе** во время разговора (D2).

**6. Инструменты и документы.**

## Риски

- Граф `.con` разобран эвристически; шаг 0 может уточнить ветки (особенно китайские).
- Сцены от третьего лица нельзя прогнать мостом — ветки проверяются только вручную.
- Если озвучка `SocialBoss` не попала в аудиопакет — реплики пойдут без звука
  (исправляется пересборкой, не ConEdit).
- Изменения ветки и комментариев делаются в рантайме; сам `.con` не меняется.
